ThemeService Verification Checklist:
  • Switch to Dark: Adds .dark class to document root element.
  • Switch to Light: Removes .dark class from document root element.
  • Persistence: Saves choice into localStorage.getItem('app-theme-preference').
  • OS Detection: Falls back to window.matchMedia('(prefers-color-scheme: dark)') if unconfigured.
  • Centralized: Zero direct DOM/localStorage access inside components; Topbar and App inject ThemeService.

Section B: Toast Notification System

Active Notifications: {{ toastService.count() }}

Centralized reactive notification management via ToastService and the global ToastContainer. Supports multiple simultaneous toasts, auto-dismiss timers, countdown progress indicators, accessible ARIA roles, and dark mode.

Show Success Toast Show Error Toast Show Warning Toast Show Info Toast Show Multiple Toasts Show Persistent Toast Clear All Toasts
Toast Notification System Verification Checklist:
  • Global Container: Single app-toast-container mounted at the application root.
  • Automatic Dismissal: Configured duration (default 4000ms) with animated timer countdown bar.
  • Manual Dismissal: Clickable close icon on every toast cleans up timers without memory leaks.
  • Simultaneous Toasts: Multiple notifications stack cleanly with responsive positioning.
  • Persistent Notifications: Configured with duration: 0 stays until manually dismissed.
  • Accessible: Emits proper role="alert" or role="status" and aria-live.
  • Dark Mode: Automatically adjusts elevation, borders, and colors to .dark theme.
